# v0.1 实施计划

| Phase | 依赖 | DoD | Test surface |
|---|---|---|---|
| P1 已验证：基础与 vertical slice | baseline + audit | docs、独立 bundle build/typecheck/test/pack；安装/dump/web boot；两错→weak→review→revision | unit、SQLite restart/failure/concurrency、Host integration |
| P2 下一阶段：课程证据 | P1 | Course/Source/Chunk、TXT/MD、PDF 有降级；稳定引用 | hash 去重、parser timeout/recovery、course isolation/locator |
| P3 Agent 学习用例 | P2 | outline/quiz/plan draft validation，grounded QA | tool contract + 独立 semantic LLM acceptance |
| P4 学习 UI | P1 + P3 | 交互 quiz、feedback、弱点与计划变更解释 | browser flow、answer-key hiding、retry |
| P5 课程交付 | P4 | 完整 golden path + pinned tarball/profile/Docker compose | packed install、cold boot、3-day demo |

不把 OPTIONAL 集成放到 critical path；达到最低文档控制面后立即编码，计划不重定义架构。第一轮交付到 P1，完整 MVP 由 P2–P5 连续演进。
